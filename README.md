# Meredith Ma — Portfolio

A responsive GitHub Pages portfolio for software engineering, AI/ML, UI/UX, cognitive science, and HCI work.

## Local preview

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish

Create a public GitHub repository named `moliere73.github.io`, copy these files into its root, commit, and push to `main`. GitHub Pages will publish the site at `https://moliere73.github.io`.

```bash
git add .
git commit -m "Build personal portfolio"
git push -u origin main
```

## Before publishing

- Replace the placeholder LinkedIn links in `index.html` with your exact profile URL.
- Confirm the public email address in the footer.
- Update any repository URL whose GitHub name has changed.
